# FlipMargin

A free, private resale profit calculator. Estimate net profit, return on purchase cost, fees, total costs, and break-even sale price before you list an item.

**Try it:** https://noka-no.github.io/flipmargin/ (if GitHub Pages is enabled)  
**Source:** https://github.com/Noka-No/flipmargin

## Use it

Open `index.html` in a browser. Enter the purchase cost, prep and packaging costs, shipping, expected sale price, marketplace percentage fee, fixed payment fee, and other costs. Results update as you type. Use **Print results** to save or print an estimate.

## What it calculates

- Estimated net after entered costs and fees
- Return on purchase cost
- Break-even item price
- Fee and cost breakdown

## Privacy and limits

All calculations run locally in the browser. The page does not upload or store entered values. FlipMargin is a general-purpose estimate, not tax, accounting, or investment advice. Marketplace fees, taxes, refunds, shipping, and payout rules vary; enter the applicable values from your own account and verify before purchasing inventory.

## Run locally

Download or clone this repository and open `index.html`. No build tools, account, or network connection are required after download.
